shikou-youtube

YouTube チャンネル「思考力トレーニングログ」の運営者が、自分のチャンネルへの動画のアップロードとコメント投稿を自動化するために使う個人用ツールです。運営者本人以外は利用しません。

This is a personal tool used only by the owner of the YouTube channel "思考力トレーニングログ" to automate uploading videos and posting comments to their own channel.

プライバシーポリシー / Privacy Policy

  • このツールは YouTube Data API を通じて、運営者本人の YouTube アカウントにのみアクセスします。
  • 取得・利用するのは、運営者本人のチャンネルへの動画アップロード、動画の公開状態の確認、コメントの投稿に必要な情報だけです。
  • 認証情報は運営者本人の機器にのみ保存し、第三者に提供・販売・共有することはありません。
  • 運営者以外のユーザーのデータを収集することはありません。
  • This tool accesses only the owner's own YouTube account via the YouTube Data API.
  • It uses only the data needed to upload videos to the owner's channel, check their privacy status, and post comments.
  • Credentials are stored only on the owner's own devices and are never sold, shared, or transferred to third parties.
  • No data from any other user is collected.

YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。
